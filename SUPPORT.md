# Support

Codebase Guard is a community-maintained project. The issue tracker is the best
place for reproducible product problems and improvement requests.

- Use the bug form for crashes or incorrect behavior.
- Use the false-positive form when safe code is flagged.
- Use the feature form for new detections or UX ideas.
- Use private vulnerability reporting for security weaknesses in Codebase Guard.

Before reporting a scanner result, capture the extension version, rule ID,
severity, relative file path, and a minimal sanitized example. Never post
credentials, session tokens, personal information, client code, or unredacted
reports publicly.

Marketplace installation and indexing can lag behind a release. Confirm the
extension ID is `mh-jsx.frontend-guard` and include whether you are using VS
Code or Cursor.
